## Usage rules

- Never place character artwork inside assignment, evidence, submission, or reviewer forms.
- Keep original SVG files local; do not hotlink runtime assets.
- Preserve the Lansiraj token palette when editing or exporting.
- Decorative derivatives use empty alt text. Informative scenes need slot-specific Macedonian alt text.
- Do not deploy a supplied asset until its commercial license is recorded here.
